`manifest.json` changes only its `Version`: the dependencies stay `Ziggfreed:MMOSkillTree ^1.7.1` and `Ziggfreed:ZiggfreedCommon >=2.3.0`. No shipped id changes.

- **Changed: the Taming level rewards are collected.** `Server/MMOSkillTree/CommandRewards/MMOSkillTamingPack.json`'s three `/mmoboost give` rows (Taming 15, 50 and 100) set `autoClaim` false, where they ran at level-up, and each gains a `localizationKey`: a command reward with no name renders no card on the skill's Rewards page, and without `autoClaim` it would never pay. New keys in `Server/Languages/<locale>/mmoskilltree.lang`: `reward.pack_taming_boost.title` (the 15 and 50 rows, "Taming XP Boost") and `reward.pack_taming_boost_all.title` (the 100 row, "XP Boost for Every Skill"). Collecting a row runs its command as the console for that player, which hands over a boost token for the Boosts tab. With MMO Skill Tree 1.7.2 a named boost card reads its multiplier and minutes as its description; on 1.7.1 it shows the name alone.
